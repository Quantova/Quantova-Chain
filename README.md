# Quantova Chain

This repository holds the Quantova chain stack. It carries the canonical codec, the account model, the transaction and block and state formats, the post quantum networking layer, the mempool, and the node binary. It is the integration point where every other component comes together. Governed by the crypto policy in the Quantova Specs repository. Commits are authored by the owner only.
